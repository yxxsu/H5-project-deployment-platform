# H5 项目部署平台 产品优势说明

一个用 PHP 7.4 + MySQL 搭建的轻量级 H5 项目托管系统。它解决的核心问题是:把本地写好的 HTML/CSS/JS 或整站压缩包,在几分钟内变成一个可对外访问的线上链接,无需配置服务器、无需懂命令行,普通用户也能自助完成。

下面从部署效率、访问分享、安全防护、使用体验、后台管理、安装门槛六个维度,说明它相比"手动传文件到服务器"的传统方式带来的实际好处。

## 三种部署方式 覆盖几乎所有上线场景

平台把"上线一个 H5"拆成三条路径,无论你手里是单段代码、单个文件,还是一整套带资源的项目,都能直接走对应入口。

| 部署方式 | 适用场景 | 操作要点 |
| --- | --- | --- |
| 代码编辑部署 | 临时写一个落地页、改一段样式 | 在控制台填写文件名(如 `index.html`),粘贴代码,点保存即生成链接 |
| 单文件上传 | 一张图片、一个 JSON、一个独立 JS | 选择本地文件,一键上传,支持 html/js/css/json/png 等常见类型 |
| ZIP 压缩包部署 | 完整的多文件项目(含图片、多页面) | 打包成 zip,根目录放好 `index.html`,上传后整站自动解压部署 |

第三种方式对前端开发者尤其友好——本地构建好的 dist 目录直接打包上传,线上结构和本地完全一致,省去了逐个文件传 FTP 的繁琐。

## 短链分享 即传即用

每部署一个项目,系统会用 32 位随机字符串生成一条访问短链(形如 `域名/api/link.php?url=xxxx`)。这条链接有三个好处:

- **不可猜测**:随机串长度足够,别人无法通过枚举撞到你未公开的项目。
- **即传即用**:上传完成的同时链接就生效,无需等待构建或发布流程。
- **统一管理**:所有项目链接集中在控制台列表里,支持一键复制、在线预览,不用自己记地址。

## 多层安全防护 让你的项目和账号都安心

这是平台花功夫最多的部分。对普通用户而言,它意味着两件事:你的项目不会被别人恶意篡改,你的账号也不易被盗用。

**账号与登录层面**

- 登录、注册全程 CSRF 令牌校验,防止跨站请求伪造。
- 登录成功后自动重新生成会话 ID,阻断会话固定攻击。
- 密码使用 `password_hash` + bcrypt 加盐存储,数据库泄露也无法反查明文。
- 登录失败统一提示"账号或密码错误",不暴露账号是否存在,杜绝账号枚举探测。

**项目访问层面**

- 每个用户的文件存放在独立空间目录,互相隔离,无法越权访问他人项目。
- 访问链接经过路径遍历校验(realpath 比对),`../` 之类手段无法跳出用户目录读取系统文件。
- 阻断 `php://filter` 等流包装器,防止通过协议读取服务器源码。
- 文件下载附带 `X-Content-Type-Options: nosniff` 与正确 MIME 映射,避免浏览器把文本当脚本执行。
- CDN 引用的 jQuery、FontAwesome 均带 SRI 完整性校验,资源被劫持篡改时浏览器会直接拒绝加载。

**后台防护层面**

- 管理后台单独鉴权,只有管理员(ID=1)可进,并叠加 CSP 内容安全策略头。
- 支持 IP 黑名单:可疑 IP 一键封禁后,该地址全程无法访问平台任何接口。

## 现代化界面 用着不累

控制台采用毛玻璃(Glassmorphism)设计语言,整体观感和交互都向当下主流的 SaaS 产品看齐:

- **深色 / 浅色主题一键切换**,选择会记在本地,下次打开自动恢复。
- **响应式布局**,手机、平板、桌面都能正常操作,移动端也能随时上线项目。
- **卡片悬浮动效、Toast 提示、模态弹窗**等反馈细节齐全,每一步操作都有明确回应,不会出现"点了没反应"的困惑。
- 主题色可在安装时和后台自定义(仅限非蓝紫色),方便接入方做品牌统一。

## 配套管理后台 运营省心

平台不只是给个人用户用的,也考虑了运营一个公开托管服务的场景。管理员后台提供三块能力:

- **系统设置**:调整普通用户的存储空间上限(MB)、全局主题色,无需改代码。
- **用户管理**:查看全部注册用户,支持一键封禁 / 解封,超级管理员不可被封,保证后台始终可控。
- **IP 封禁管理**:针对恶意访问或刷接口的 IP,手动加入黑名单即时拦截。

管理员自身没有容量限制,适合用来托管官方示例项目或大型演示页面。

## 安装门槛低 几乎零依赖

整套系统对运行环境的要求很克制,一台普通的虚拟主机或轻量云服务器就能跑起来:

- PHP 版本 ≥ 7.4,只需开启 `pdo_mysql` 与 `zip` 两个扩展。
- 一个 MySQL 数据库,无需手动建表——安装向导会自动创建用户表、短链表、IP 黑名单表、配置表。
- 提供三步可视化安装向导:环境检测 → 数据库配置 → 创建管理员,全程网页操作,几分钟完成。
- 安装时会自动检测 PHP 版本、扩展、目录可写权限,缺什么一目了然,避免上线后才发现报错。

数据表支持自定义前缀(默认 `deploy_`),方便和其他系统共用同一个数据库而不冲突。

## 适合谁用

- **前端开发者**:本地写完 H5 想快速发个预览链接给客户看,不想折腾部署。
- **运营 / 市场**:活动落地页、H5 海报需要临时上线,希望自助完成而非提工单。
- **教学 / 培训**:学员上传作业作品,老师统一查看,有空间限额和封禁能力兜底。
- **小团队内部托管**:搭一个私有的静态资源分发入口,带权限和审计。

总的来说,这个平台把"传文件到服务器"这件原本需要懂运维的事,降维成了一个网页表单操作,同时在安全上做了远超同类小工具的防护投入。对使用者而言,省下的是部署时间;对运营者而言,省下的是后续被攻击、被滥用的补救成本。
